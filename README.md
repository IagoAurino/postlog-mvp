# PostLog - Passagem de Turno (MVP)

## 📋 Sobre o Projeto
O PostLog é uma aplicação web desenvolvida para modernizar a passagem de turno na segurança patrimonial e controle de acesso. Substituindo o tradicional livro de ocorrências de papel, o sistema oferece checklists digitais, registro de ocorrências e autenticação segura, trazendo mais agilidade e dignidade para a guarita (alinhado ao ODS 8 - Trabalho Decente).

## 🚀 Tecnologias Utilizadas
- HTML5, CSS3 (Glassmorphism) e JavaScript
- Design Responsivo e Acessível (Alto contraste e botões otimizados)

## 🛠️ Como executar
1. Clone o repositório: `git clone https://github.com/IagoAurino/postlog-mvp.git`
2. Abra o arquivo `index.html` em seu navegador web.
